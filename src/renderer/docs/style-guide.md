# 面板风格规范 · 深色菜单（v1）

> 适用范围：设置窗（settings.html）。气泡面板暂不换，待后续决策。
> 风格来源：Claude 桌面端账户菜单（用户提供参考图，2026-08-29）。

## 色板（纯灰系，不带蓝紫倾向）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--card` | `#1a1a1e` | 面板底 |
| `--card2` | `#26262b` | 行悬停 |
| `--line` | `#2e2e36` | 分隔/边框（极淡，少用作分割线） |
| `--text` | `#ececec` | 主文字 |
| `--dim` | `#9a9aa2` | 值列 / 快捷键 / 次要文字 |
| `--faint` | `#6b6b73` | 组标题 |
| `--red` | `#f0716c` | 危险操作（退出等） |

## 结构

```
面板
├─ 标题区（可选）
└─ 分组 ×N
   ├─ 组标题：10px / letter-spacing 2px / faint，仅文字无横线
   └─ 行 ×N
      ├─ 图标：16px lucide 风格 stroke SVG（stroke-width 1.7，圆角线帽）
      ├─ 标签：13px text 色，紧跟图标（gap 10px）
      └─ 右值：12px dim 色（状态值 / › 箭头 / 快捷键）
```

## 尺寸与间距

- 面板圆角 14px；行圆角 8px
- 行内 padding：8px 10px（行高约 36px）
- 分组之间：**靠留白分隔，不用分割线**（margin 8px+）
- 滑杆：轨道 2px 高 line 色，滑块 12px 白圆（保持现有交互）

## 规则

1. 颜色一律走色板令牌，不写死色值
2. 行图标必须成体系（同 stroke 宽度、同视觉重量），宁缺毋滥
3. 危险操作整行红色（含图标与右值），悬停用 10% 红底
4. 禁用行：faint 色、无悬停反馈
