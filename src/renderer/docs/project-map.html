仓库结构

mind-board-pet/
├── index.html                产品主页（GitHub Pages 首页）
├── 喵喵启动.bat              Windows 一键启动
├── package.json              start=electron · pet=纯服务模式 · test=冒烟
│
├── src/core/                 ★ 数据中枢（唯一事实源，零依赖）
│   ├── store.mjs             四层骨架 · organize 合并/去重/supersedes ·
│   │                         漂移防护 · 原子写盘 · journal · 概览聚合
│   └── protocol.mjs          AI 协议：四层定义 + 11 条规则 + 状态行
│
├── src/mcp/server.mjs        MCP stdio 服务：organize / query / control
│
├── src/hooks/                Claude Code 钩子（AI 注入通道）
│   ├── session-start.mjs     会话开始 → 注入完整协议
│   └── prompt-submit.mjs     每轮 → 注入一行状态 + tick 计数 + 调试追踪
│
├── src/server/app.mjs        本地 HTTP（127.0.0.1:13134）：REST API + 静态页
│
├── src/main/main.cjs         ★ 窗口编排：5 窗生命周期 · z-order · 防抖/宽限 ·
│   │                         光标轮询 · 拖拽吸附 · 热键 · 托盘 · 开机自启
│   ├── preload.cjs           桥：穿透/环/面板/设置/仪表盘/芯片矩形
│   └── noop-preload.cjs      面板桥：图钉 · 缩放 · 开仪表盘 · 外链
│
├── src/renderer/             展示层（全部无构建，直接由本地服务托管）
│   ├── pet.html / pet.js     猫窗：皮肤装载 · 命中 · 心跳探针
│   ├── skins/cat/            小黑猫皮肤：三姿态 · 呼吸 · 拎起弹簧
│   ├── dock 圆环（C# 原生，M2）图标环：3s 流水线 · 扇形布局 · 恒驻+光效
│   ├── bubble.html/js/css    思维板面板：四层渲染 · 拖拽删除 · 总览
│   ├── settings.html         设置窗
│   ├── dashboard.*           项目总览仪表盘（1160×800 大窗口）
│   ├── assets/               猫素材 + harness 图标（dsh 鲸等）
│   └── docs/                 图解与文档（本页 · 组件图解 · 算法 · 方法论）
│
└── scripts/                  smoke-test · check-assets · swap-pose 等

数据目录（仓库外）：~/.mind-board/  →  projects/ · skeletons/ · journal.jsonl · settings.json

模块职责与依赖方向

端到端数据流

数据产生消费
四层骨架条目AI organize（MCP/HTTP）→ mergeList 合并去重 → 原子落盘面板 loadSkeleton · query 工具 · dashboard 卡片
journal.jsonlstore 每次真实变更追加事件桌宠 tail 驱动动效；审计追溯
liveAtMs（文件 mtime）钩子 tick / organize 写盘图标环存活判定（光晕）· 仪表盘「运行中工具」
settings.json设置窗 / 面板偏好 / 窗口位置记忆所有窗口启动时读取
chip-rects（内存）dock 每 3s 上报芯片屏幕矩形猫窗命中排除——芯片点击永不截胡
