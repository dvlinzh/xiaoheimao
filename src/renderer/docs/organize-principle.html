① organize() 决策流水线

五个阶段依次执行——不是所有调用都值得写入，任何一个阶段都可能「什么也不做」。

② 去重的尺子：字符 bigram Jaccard

中文不分词也能比相似度：把字符串切成「相邻两字」的集合，算交并比。无需词典、无需分词器。

③ 条目生命周期状态机

每个条目一条单向生命周期。统计与渲染只认有效状态，退场条目保留在数据里可审计。

④ 衰减与统计口径

「乱七八糟」的另一半解药在显示层：退场与陈旧内容降调，数据保留可审计。

⑤ 收敛闭环：一次整理的完整例子

// 轮 1：用户聊到深色模式
organize({ ideas:[{ text:"深色模式" }] })
→ ideas +1（active）

// 轮 3：聊清楚了一点
organize({ points:[{ text:"深色模式要做，方案未定" }] })
→ points +1（active）

// 轮 5：敲定（bigram ≥0.7 命中原条目 → 更新而非新增）
organize({ points:[{ text:"深色模式要做", decided:true }] })
→ decided = true

// 轮 9：方案演进，旧结论被取代
organize({ points:[{
  text:"深色模式：CSS 变量方案", decided:true,
  supersedes:["深色模式要做"]          ← 旧原文，或旧条目 id
}] })
→ 新条目 +1；旧条目标记 superseded（退场，数据保留）

// 14 天后没人再动的缺口 → 显示层自动划线降调，统计移入「陈旧」
