以「思维板小黑猫」为中心的概念全景。四个主分支 = 四类关注点。

文字版全图

思维板·小黑猫
├── ① 四层模型（成熟度管线：想法→缺口→方案→要点）
│   ├── 想法 = 自然语言初步设想（原始素材，归纳入库）
│   ├── 缺口 = 设想到落地的逻辑闭环缺失（驱动推进）
│   ├── 方案 = 填充缺口的候选路线（adopted 唯一）
│   └── 要点 = 重点预览 + ↗完整版链接（项目地图/图解/流程图收录于此）
├── ② 接入层（三条标准通道）
│   ├── Hooks：会话协议 + 每轮一行状态
│   ├── MCP stdio：organize / query / control
│   └── HTTP：本地 API + 静态页（浏览器兜底）
├── ③ 桌宠壳（可抛弃展示层）
│   ├── 猫窗（逐像素命中 · 呼吸 · 拎起摆动）
│   ├── 图标环（恒驻 · 扇形 · 运行光晕）
│   ├── 面板（默认钉住 · 拖拽删除 · 总览视图）
│   └── 设置 + 仪表盘
└── ④ 数据与生命周期
    ├── draft → clarifying → reflected → archived
    ├── supersedes 替代链（旧认知退场）
    ├── 14 天缺口衰减
    └── 原子写盘 + journal 事件流
