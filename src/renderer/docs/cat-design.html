小黑猫 · 角色设计概念方案

来源：洛克王国：世界 ｜ 桌宠 + 思维板面板整体视觉重构 ｜ 2026-08-28

①设计原点

小黑猫是《洛克王国：世界》中的猫精灵，种族资质 491，特性「预警」。官方设定原话：「在白天，小黑猫们经常闭上眼睛，揣着手休息……小黑猫闭眼就是在思考。」

这句话是整个设计的原点——它不是一只卖萌的猫，是一只在思考的猫。这和思维板「随手整理、安静沉淀」的气质完全同频。桌宠的常态不是「盯着你等指令」，而是「眯着眼在帮你琢磨」。

设计原则：一切视觉元素取自猫本体，不引入外来符号。面板层级色 = 眼睛色，进度条 = 拖尾，警示 = 怒焰，采用方案 = 许愿星（wiki 技能名）。

⑤五个互动动作（详细规格）

1
眯眼思考
idle 常态。眼睛从全睁渐眯成半月（0.6s ease），青纹亮度脉动（呼吸灯），紫焰以 2s 周期轻摇。整体传达「它在帮你琢磨」。
触发：默认待机态 ｜ 时长：持续 ｜ 动画：SVG path morph + opacity pulse
2
紫焰摇曳
常驻微动，不打断任何状态。耳间紫焰以 2s 正弦周期轻摆（±3px 振幅），拖尾以 3s 周期缓缓飘动（路径 morph）。呼吸感的来源。
触发：常驻 ｜ 时长：无限循环 ｜ 动画：CSS transform rotate + SVG path morph
3
星星坠落（许愿星）
双击触发彩蛋。一颗金色五角星从头顶上方落下（0.8s），猫仰头顶住（0.3s），星星碎成 4 颗小星散开消失。取自 wiki 技能「许愿星」——他们为了愿望而来。
触发：双击 ｜ 时长：1.5s ｜ 动画：CSS translateY + scale + opacity
4
怒焰
新缺口写入时触发。眼睛瞬间变红（0.1s），紫焰转红焰并加速摇曳（1s 周期），拖尾变红橙渐变。持续 3 秒后渐回眯眼常态。不吓人，是「皱眉」不是「发火」。
触发：新缺口 ｜ 时长：3s ｜ 动画：fill/gradient transition + path morph
5
揣手休息
整理模式关或 10 分钟无数据。猫趴下（身体压扁 0.4s），前爪收拢，眼睛闭合，青纹熄灭，紫焰缩小。呼吸起伏以 4s 周期轻微缩放（±1px）。完全安静，不打扰。
触发：模式关 / 超时 ｜ 时长：持续 ｜ 动画：scaleY + opacity fade
+
许愿星庆祝
缺口清零瞬间触发。猫跳起（translateY -20px，0.3s），空中转半圈，落地弹一下（0.2s），拖尾甩出一道弧线残影。同时 2 颗小星星从耳间飞出消散。
触发：缺口清零 ｜ 时长：0.8s ｜ 动画：CSS transform + SVG path trail

⑦工艺决策

SVG 矢量，不是像素也不是照片。

理由：小黑猫是赛璐璐 2D 角色——干净色块 + 流畅曲线 + 柔和发光。像素画会破坏曲线的流畅感（上轮 KDB 用像素是因为照片马赛克天然适合），照片管线不适用（非真人）。SVG 是唯一能在 190×220 窗口里同时做到「极高还原度」和「生动活泼」的工艺。

皮肤 API 不变：mount(host) → { setMood, hop, juggle, flash }。动效全部 CSS/SVG 动画，零 JS 定时器。
