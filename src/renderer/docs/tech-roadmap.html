⚠ 技术债与风险（诚实清单）
  1. 拖拽失效（当前首伤）：mousedown 未达渲染层（probe 日志为证）。主嫌：focusable:false 窗口事件、透明像素命中、窗口移动抢捕获。已加日志探针，逐项排除中。
  2. 整理是软约束：模型偶尔跳过 organize 调用；每轮状态行会把它拉回来，但不是 100%。
  3. dev 模式自启禁用：需 P4 打包后解锁。
  4. DSH 双数据源：对接前两边各自为政，骨架不同步。
